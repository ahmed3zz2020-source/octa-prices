## ٣) حالة الـdeploys —Railway

### ٣.١ الـCI كان أحمر على كل commit (السبب الحقيقي)

الـCI كان بيفشل على **كل** commit من ٢٤ أكتوبر. ده الـ«٥ deploys فاشلة» اللي في الذاكرة — **مش deploys فاشلة، الـCI كان أحمر**.

```
2026-10-25T03:27:54Z  failure  37dbab7   ← آخر commit
2026-10-25T03:02:30Z  failure  e431b2c
2026-10-24T22:25:58Z  failure  e9b7252
2026-10-24T22:07:20Z  failure  c84a7c7
2026-10-24T21:58:13Z  failure  c1620ac
2026-10-24T19:17:09Z  failure  51421da
... (١٠+ commit)
```

**السبب — فحص كاذب (False positive):**
```bash
if grep -n '\.\.\.' update_prices.py | grep -v '^\s*#'; then
```
`grep -n` بيحط **رقم السطر قبل النص** ⇒ السطر بيبقى:
```
951:        # 📌 Response(jsonify(...)) ⇒ 500 بدل 429.
```
فلتر `grep -v '^\s*#'` بيدوّر على سطر يبدأ بـ«#» — بس السطر بيبدأ بـ`951:` ⇒ الفلتر **مش بيلاقي حاجة** ⇒ الفحص بيفشل **دايماً**.

**الدليل:**
```bash
$ grep -n '\.\.\.' update_prices.py | grep -v '^\s*#'
951:        # 📌 Response(jsonify(...)) ⇒ 500 بدل 429.
2506:    # 📌 الشكل القديم: Response(jsonify(body), status=429, ...)

$ grep '\.\.\.' update_prices.py | grep -v '^\s*#'
(فاضي)          ← الكود سليم!
```
السطرين **كومنت حقيقي** (مش خطأ لصق) ⇒ الكود سليم ١٠٠٪ والـCI كاذب.

**الإصلاح — ليه مش عدّلنا الـworkflow؟**
ملف `.github/workflows/ci.yml` محمي من GitHub: التوكن المتاح scope بتاعه `public_repo` بس، وGitHub **رفض**:
```
refusing to allow a Personal Access Token to create or update workflow
`.github/workflows/ci.yml` without `workflow` scope
```
⇒ **الحل البديل:** شِلنا الـ`...` من الكومنتين بس (سطرين كومنت بحت — صفر تغيير سلوك).

**النتيجة:** PR #1 — الـCI بقى **أخضر بالكامل** (كل الخطوات success).

## ٥) جدول كل الـendpoints

**٨٦ endpoint مُفحص** (٩٧ route في الكود — الـdifference routes الـOPTIONS + preflight + aliases).

**الحماية متظبطة في ٣ طبقات:**
1. **ديكوريتور** `@_require_user` — على `/api/stocks` و `/api/markets`
2. **فحص جوّه الدالة** `if not require_user():` — على ٢٩ مسار
3. **قبل الـrequest** `@app.before_request protect_admin_routes` — على ٣ مسارات تشخيصية
4. **توكن أدمن** `X-OCTA-Admin` + `hmac.compare_digest` — على ٨ مسارات `/api/admin/*` (fail-closed: مافيش توكن = 503)

**الحماية مُتحقَّق منها عملياً** — كل مسار محمي رجّع **401** من غير أي توكن (فحص بدون هيدرات خالص).
