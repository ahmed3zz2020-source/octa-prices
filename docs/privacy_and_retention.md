# 🛡️ سياسة الخصوصية والاحتفاظ بالبيانات — OCTA
**الإصدار:** `r26-privacy-v1` · **التاريخ:** ١٩ نوفمبر ٢٠٢٦ · **الجولة:** ٢٦ (R26)

> 📌 هذه الوثيقة **ملزِمة** ومتسقة مع الكود: كل سطر هنا له موضع في الكود
> (`subscription_core.py` + `subscription_api.py` + `update_prices.py`).
> أي تعديل في الكود لازم ينعكس في هذه الوثيقة والعكس.

---

## ① نطاق الوثيقة

تشمل:

- بيانات **الاشتراك** (الباقة · السعر · تاريخ البداية والنهاية · الحالة).
- بيانات **الدفع** (محاكاة محلية) وسجل المعاملات (ledger).
- **تذاكر الدعم الفني** ومحتواها.
- **مفاتيح تفرّد الطلبات** (idempotency) و**أحداث التسوية**.
- **إيصالات حذف الحساب**.

⛔ **لا تشمل** (ومكتوبة في مكان تاني): بيانات الحساب الأساسية
(البريد · الاسم · الباسورد · البصمة) — دي في `users.json` ولها سياستها
الخاصة في مسار حذف الحساب (`update_prices.py`).

## ④ حقوق المستخدم

| الحق | المسار | النتيجة |
|---|---|---|
| معرفة حالة الاشتراك | `GET /api/billing/me` | حالة + صلاحيات + آخر عملية دفع |
| معرفة الصلاحيات | `GET /api/billing/entitlements` | الحدود الفعلية (فرص · تنبيهات · RealView) |
| معرفة سجل المدفوعات | `GET /api/billing/payments` | سجل العمليات الخاص بالمستخدم |
| إلغاء الاشتراك | `POST /api/billing/cancel` | إلغاء فوري أو بنهاية الفترة |
| طلب استرداد | `POST /api/billing/refund` | استرداد + رفع الصلاحيات فوراً |
| **حذف الحساب** | `POST /api/auth/delete` | حذف كل البيانات + إيصال حذف |

⛔ **مافيش** بيع بيانات · مافيش مشاركة مع أطراف ثالثة · مافيش إعلانات
مغلقة بالاشتراك · مافيش كتابة بالحد الأدنى للاشتراك (قرار المستخدم).

## ⑤ حذف الحساب — الأثر الموثّق

📌 **المطلوب**: حذف بيانات الاشتراك + المحفظة + التنبيهات + توثيق الأثر.

**الترتيب (في `update_prices.py` ⇐ `auth_delete_account`):**

1. تحقق: توكن جلسة صالح + الباسورد + كتابة `DELETE` في الخانة.
2. تصفير `watch` (التنبيهات) و`portfolio` (المحفظة) داخل `users.json`.
3. إبطال كل الجلسات (`token_epoch`).
4. **الجولة ٢٦**: `subscription_core.purge_user_data(uid)` ⇐ بيمسح من
   `subscriptions_v2/`: الاشتراكات · المدفوعات · محفظة المعاملات ·
   تذاكر الدعم · مفاتيح التفرّد · أحداث التسوية.
5. **الأثر** بيتوثّق في:
   - رد الحذف: `subscription_purge = {deleted, removed{...}, receipt_policy}`.
   - **إيصال الحذف** في `subscriptions_v2/receipts.json` — بيحتوي **فقط**:
     هاش المعرّف (`uid_hash`) + وقت الحذف + عدّادات السجلات المحذوفة +
     اسم السياسة. ⛔ **مافيش** بريد · مافيش اسم · مافيش باقة · مافيش مبلغ.
6. **إلغاء** `watch` و`portfolio` بيحصل في `users.json` قبل خطوة 4.

⛔ **الاحتفاظ بعد الحذف (معلن صراحة):** إيصال الحذف فقط، لمدة **سنة**،
ثم بيشيله `sweep()`. الغرض: منع إعادة التسجيل بالحساب نفسه + إثبات تنفيذ
الطلب. **مافيش** أي بيانات شخصية مقروءة بعد الحذف.

## ⑥ دورة الاحتفاظ — كيف بتنفّذ فعلياً

📌 **جدول الأرقام كما في الكود بالظبط** (المصدر: `subscription_core.py` ⇐ `RETENTION`) —
كل قيمة دي **عدد أيام**، والاختبار `tools/test_r26_subscriptions.py` بيقارن
الجدول ده بالثابت في الكود:

| المفتاح في الكود | القيمة (أيام) | المعنى |
|---|:--:|---|
| `idempotency_days` | 2 | مفتاح تفرّد الطلبات (٤٨ ساعة) |
| `failed_payment_days` | 90 | محاولة دفع فاشلة |
| `payment_days` | 730 | عملية دفع ناجحة ومحفظة المعاملات (سنتان) |
| `subscription_days` | 730 | اشتراك منتهي/ملغى/مستردّ (سنتان) |
| `settlement_days` | 730 | حدث تسوية (سنتان) |
| `support_closed_days` | 365 | تذكرة دعم مغلقة (سنة) |
| `deletion_receipt_days` | 365 | إيصال حذف الحساب (سنة) |
| `pending_checkout_days` | 30 | سلة دفع معلّقة لم تُسدّد |

📌 `subscription_core.sweep()` — تنظيف دوري (يستدعيه الأدمن من
`POST /api/billing/retention/sweep`):

| السجل | القاعدة |
|---|---|
| مفاتيح تفرّد الطلبات | تُشال بعد **٤٨ ساعة** من إنشائها |
| المدفوعات الفاشلة | تُشال بعد **٩٠ يوم** |
| المدفوعات الناجحة · محفظة المعاملات | تُشال بعد **سنتان** |
| الاشتراكات المنتهية/الملغاة/المستردّة/المستبدَلة (superseded) | تُشال بعد **سنتان** |
| أحداث التسوية | تُشال بعد **سنتان** |
| تذاكر الدعم المغلقة | تُشال بعد **سنة** |
| إيصالات حذف الحساب | تُشال بعد **سنة** |
| سلة الدفع المعلّقة (لم تُسدّد) | تتحوّل لـ `expired` بعد **٣٠ يوم** |

📌 **حدود القبول مش متغيّرة**: الاشتراك بيحدد **العرض** (كام فرصة · كام
تنبيه · RealView) — مش بيغيّر أي وزن محرك ولا حد قبول ولا سياسة استثمار.
