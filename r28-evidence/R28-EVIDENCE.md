## ١ · الخلاصة

أُغلقت ثغرة كلمة مرور لوحة الإدارة (تسريب حالة + استنزاف تخزين)، وأُغلقت ملاحظات المعاينة R26-I01..I05 كلها، ونُشر العامل الحيّ بمخزن قوي ومساحة KV منفصلة، وأصبح سجل الاعتماد (١٤٤ بندًا) يُبنى بأداة ثابتة داخل المستودع بلا نسبة موروثة.

ما زال خمسة بنود لا تنفَّذ إلا بصلاحية من المالك: تدوير توكن تيليجرام، نشر الـbackend على Railway، توكن بصلاحية workflow لتفعيل الـCI على GitHub، تفعيل Secret Scanning + Push Protection، وصلاحيات Access/WAF.

## ٦ · ما يحتاجه المالك (خمسة بنود ⭐)

1. **Railway**: `project_id` + توكن صالح (أو نشر خدمة staging يدوي) ⇒ رابط الباك الحيّ بدل tunnel.
2. **توكن بصلاحية `workflow`** ⇒ تفعيل `.github/workflows/ci.yml` على GitHub (أو نشر الملف بمحرر الموبايل).
3. **تدوير توكن تيليجرام**: إلغاء القديم (ميت فعلًا) وإنشاء جديد عبر @BotFather وضبطه في Railway + إبطاله في المستودعات.
4. **GitHub Secret Scanning + Push Protection**: التفعيل من Settings ⇒ Code security (الـAPI يرفض ⇒ لا محوّل آلي).
5. **Cloudflare Access + WAF**: إنشاء التطبيق وقواعد الحماية.
